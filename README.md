# مِرقاب — النسخة الموسعة (MVP)

موقع عربي متجاوب لإدارة الدراسة: المواد، المحاضرات، المصادر، مهام المذاكرة، جلسات التركيز، التقارير، وطلبات النشر التجريبية.

## الملفات
- `index.html`: بنية الصفحات.
- `styles.css`: التصميم والاستجابة.
- `app.js`: منطق الواجهة والبيانات التجريبية المحلية.
- `firebase-setup.md`: خطة ربط الخلفية الحقيقية.

## نشر مجاني من الهاتف عبر GitHub Pages
1. فك ضغط ملف ZIP.
2. أنشئ مستودعًا عامًا باسم `mirqab` على GitHub.
3. ارفع ملفات المشروع الموجودة في جذر المجلد (`index.html`, `styles.css`, `app.js`, `README.md`, `firebase-setup.md`).
4. افتح Settings → Pages.
5. اختر Deploy from a branch، الفرع `main`، والمجلد `/(root)` ثم Save.
6. انتظر رابط النشر الذي يظهر في صفحة Pages.

## وظائف تعمل في النسخة الحالية
- لوحة رئيسية وإحصاءات.
- إضافة مواد ومحاضرات ومصادر ومهام.
- البحث والتصفية.
- علامة اكتمال المهام.
- مؤقت جلسات تركيز وتسجيل الجلسات المكتملة.
- طلبات نشر تجريبية وموافقة/رفض محلي.
- تصدير واستيراد نسخة JSON احتياطية.
- تخزين البيانات في المتصفح عبر `localStorage`.

## حدود مهمة
هذه ليست منصة متعددة المستخدمين بعد:
- لا يوجد تسجيل دخول حقيقي أو صلاحيات خادم.
- البيانات محفوظة في المتصفح الحالي فقط، وليست مشتركة بين الطلاب.
- «المكتبة المشتركة» و«طلبات النشر» محاكاة محلية وليستا نظام إشراف آمنًا.
- لا يوجد رفع ملفات إلى خادم؛ خيار «ملف» يسجل بيانات المصدر فقط.
- مؤقت المذاكرة يعمل بينما الصفحة مفتوحة.
- لا تخزّن معلومات شخصية أو ملفات حساسة هنا، ولا تستخدم الواجهة المحلية كدليل أمني.

## الخطوة التالية
راجع `firebase-setup.md` لربط Firebase Authentication وFirestore وCloud Storage بقواعد أمان مناسبة.
